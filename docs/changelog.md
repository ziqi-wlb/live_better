### 修线上 bug：首页「查看全文」有一半点不开

详情页数据按章节拆在两个分包（1–11 章在 `packageDetail`，12 章起在 `packageDetail2`），跳转时必须按条目所属章节选分包。

- `decorate()` 补上 `ch`
- `onOpenDaily` 加兜底：`daily` 没带 `ch` 时回 `guides` 查一次，不再依赖单一来源
- 全量验证：765 条逐条模拟跳转并校验目标分包是否含该 id，**0 失败**
- 指南页没这个问题：`guide-card` 的 open 事件带 `ch`，清单用 `chapterOf` 回源查，两条路都是对的

### 移除「存图分享」，改为零隐私接口

后台的「用户隐私保护指引」一时找不到入口，而只要调用 `wx.saveImageToPhotosAlbum` 就必须声明「相册（仅写入）」。与其带着一个必然失败的功能上线，不如先摘掉：

- 首页今日一条卡片去掉「存图分享」，只留「查看全文」（改为实心主按钮）
- 删除 `onSavePoster`（canvas 绘制 + `canvasToTempFilePath` + 权限引导弹窗）以及只为它服务的 `rr` / `wrapText`，首页 JS 238 → 95 行
- 《隐私政策》同步回退：删掉相册小节，恢复「本应用未调用任何需要授权的隐私接口」
- 结果：全项目**没有任何隐私接口调用**，后台隐私指引可直接选「未处理任何用户信息」，与代码、文本三方一致，审核不会再卡这里

以后想恢复分享图，顺序必须是：**先配后台隐私指引 → 再上调用隐私接口的代码**，反过来一定失败。

### 隐私政策与「相册（仅写入）」权限对齐

准备提交审核时发现小程序内《隐私政策》与实际代码矛盾：原文写着「本应用未调用任何需要授权的隐私接口」，但首页「存图分享」调用了 `wx.saveImageToPhotosAlbum`——**后台声明与小程序内文本不一致是常见驳回原因**，已修正：

- 新增「相册（仅写入）权限」小节，说明只在用户主动点「存图分享」时写入一张生成的图片，不读取、不上传相册内容，写入后不留副本，拒绝授权不影响其他功能
- 「我们不收集的信息」改为「不读取你的相册内容」，区分**读**与**写**
- 表述统一使用 UI 上的实际文案「存图分享」，避免审核对照时对不上
- 更新日期改为单一来源（`lastUpdated` 字段），不再在正文和页脚各写一份

### 首次上传踩到的两个坑

用 `miniprogram-ci` + 上传密钥发布时连续失败两次，都记在这里，以后别再踩：

- **`errCode -10008 invalid ip`**：密钥上传必须在 mp 后台「开发 → 开发管理 → 开发设置 → 小程序代码上传 → IP 白名单」里加 IP。注意**以报错里返回的 IP 为准**——本机 `curl ipify` 得到 `202.46.41.90`，但微信服务器实际看到的是另一个出口（`123.124.235.10`）
- **`errcode 80058 preloadRule source size exceed max limit 2MB`**：**单个页面预加载的分包总量不能超过 2MB**。之前首页和库页都同时预加载 `packageDetail` + `packageDetail2`（1153 + 1223 = 2352KB），开发工具能跑但上传被拒。已改成只预加载 `packageDetail`，`packageDetail2` 走按需下载（首次打开第 12 章之后的条目会多约 1 秒）

### 详情页沉浸式阅读：滚动隐藏导航栏

「查看全文」进详情后，导航栏跟着阅读动作自动收起：

- 继续往下读 → 导航栏淡出，把屏幕让给正文
- 往回滑 → 导航栏淡入，方便点返回
- 回到顶部区域（`scrollTop ≤ 40`）时始终显示
- 8px 抖动阈值，小幅滚动不会导致反复闪烁

实现复用 `navigation-bar` 组件自带的 `show` 属性（内部是 `opacity` 过渡、元素仍占位），所以**隐藏时布局不动、正文不会跳动**。若改成 `display:none` 或改变占位高度，正文会整体位移。两个分包的详情页是副本，已同步。

### 同义词扩展（可复用模块 `utils/synonyms.js`）

搜索「炒股」返回 0 条——语料里只有「股票/基金/投资」，2-gram 无法跨越 `{炒股}` 与 `{股票}`（无公共 bigram）。新增同义词词典修复口语问法与语料用词的落差：

- **词典**：38 组同近义词（钱/投资、看病/医保、婚育、维权、诈骗、账号安全、生活习惯、慢病等），每组词互为可匹配项；维护原则是先确认词确实出现在 `data/guides.js` 再收录，避免空转
- **权重**：原词满权重；同义词降权 `SYN_WEIGHT=0.6` 并**按组内距离递减**（`1-(i-1)*0.06`，下限 0.35），所以搜「炒股」时「股票」排在「年化」前面
- **高亮**：`expandTerms()` 把查询词展开为「自身+同义词」，搜「炒股」也能把「股票」「投资」标黄
- **放弃单字回退**：曾尝试「词整体不中时退回单字命中」，实测「存不下钱」返回 368 条、「脱发」129 条无关结果，噪音远大于收益，已移除——宁可返回空并提示换个说法
- 实测：炒股 20、失眠 13（睡眠/作息/午睡）、减肥 11、阳痿 3（勃起）、医保 53、被骗 3；脱发/颈椎/存不下钱 语料无对应内容，返回空态

### 模糊搜索（可复用模块 `utils/search.js`）

搜索从「整串子串匹配」升级为真正的模糊匹配，纯本地、无依赖：

- **多关键词**：空格/逗号/顿号/分号切分，多词之间为「且」，命中越多排越前
- **相关度打分**：标题 12（完全相等再 +8）> 摘要 5 > 章节名 4 > 人群/口径 3 > 模糊命中 1
- **2-gram 相似兜底**：词未精确命中时，用 bigram 覆盖率（阈值 0.6）判断近似
- **两阶段降级**：第一阶段要求每个词都命中；无结果时自动放宽为「命中任一词」并显示提示条「已按相关度显示最相近的条目」（`fuzzyMode`）
- **命中高亮**：`highlight()` 把标题/摘要切成 `{t, h}` 分段数组，卡片用多个 `text` 渲染（`.hit` 琥珀底），避开 rich-text 在 Skyline 的兼容问题
- **片段截取**：`snippet()` 截取命中位置附近的 72 字，避免关键词被长摘要埋掉
- 排序：有关键词时按相关度降序，同分再走原有章节/性价比/证据排序
- 搜索框占位改为「搜『租房 押金』，多个词用空格」提示多词用法
